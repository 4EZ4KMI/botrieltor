BotRieltor для Windows

Запуск
1. Установите Google Chrome и войдите в Zalo в отдельном профиле приложения.
2. Запустите BotRieltor.exe.
3. В настройках укажите доступный адрес OmniRoute, его ключ и модель.
4. В настройках Telegram подключите бота к каналу и включите публикации.
5. Нажмите «Открыть профиль Zalo приложения» и войдите в отдельный профиль Chrome,
   затем оставьте открытой группу GINSENG.

Для встроенного окна нужен Microsoft Edge WebView2 Runtime. На Windows 11 он
обычно уже установлен; если приложение сообщает, что его нет, установите Runtime.

База, профиль Chrome, журналы и локальные настройки находятся в:
%LOCALAPPDATA%\BotRieltor

У Windows своя база и свой профиль Zalo. Cookies и ключи с Mac не копируются.
Секреты, сохранённые на Windows, шифруются средствами DPAPI для текущего
пользователя Windows.
