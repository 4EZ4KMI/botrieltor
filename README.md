# BotRieltor

Локальное приложение для потока Zalo → Telegram-канал на macOS и Windows. Приложение следит
только за группой GINSENG: сначала в неё отправляют пачку фотографий, затем текст
объявления. Бот связывает фотографии с текстом, проверяет объявление и автоматически
публикует его в подключённый канал в заданном формате.

## Запуск

Готовая сборка macOS: `dist/BotRieltor.app`. Открывается отдельное окно приложения.
Нажмите «Запустить» утром, «Приостановить» для паузы, закройте приложение вечером.
Если открыто несколько окон, используйте Cmd+Q или меню «Завершить BotRieltor».
До настройки интеграций запуск показывает «Ожидание подключения Zalo».
Автозапуска при входе в macOS нет. При открытии сбор всегда приостановлен.
Во время сна Mac работа также не выполняется; после сна нужен сбор пропусков.

Сборка macOS требует установленного Python 3.11+ и инструментов разработки Apple:

```sh
python3 scripts/build_app.py
open dist/BotRieltor.app
```

Сборка привязана к пути текущего Python на этом Mac. Это не автономный дистрибутив
для других компьютеров; для переноса потребуется пересборка или упаковка runtime.
Для разработки можно запустить `python3 -m botrieltor.server` и открыть адрес
из строки `ready`. Сервис слушает только loopback, использует случайный порт,
проверку Host, токен запросов и Origin. Панель управления использует временную
WebKit-сессию. У окна Zalo отдельное сохраняемое хранилище WebKit этого приложения;
cookies из Chrome, Safari или Codex не считываются и не копируются.

## Вход в Zalo

Кнопка «Открыть в Chrome» на обзоре и в источниках открывает официальный Zalo Web
в Google Chrome. Также доступно меню Zalo → Открыть Zalo в Chrome (Cmd+L).
Встроенный WebKit убран: Zalo принимал QR-вход и показывал аватар, но не запускал
интерфейс чатов. Авторизация и cookies остаются в профиле Chrome; локальный
Python-сервис не получает пароль, QR-код или cookies.

После входа сборщик привязывает и слушает только группу GINSENG. Он сохраняет
новые сообщения и фотографии; накопленная до перехода история остаётся в архиве,
но не запускает новую автопубликацию.

## Что уже работает

- Отдельное окно приложения, запуск и пауза локального планировщика.
- Ручные карточки объектов Нячанга, поиск и фильтр, ручная отметка «Сдан».
- При запуске остаётся активным только источник GINSENG; предыдущие источники
  выключаются, а старые объявления сохраняются и не отправляются повторно.
- Фото-сообщения ожидают следующий текст объявления; после его получения бот
  прикрепляет фотографии и запускает автоматическую проверку и публикацию.
- Локальный OmniRoute подключается через OpenAI-совместимый API. Адрес и модель
  хранятся в настройках, API-ключ — в локальном хранилище приложения. В Windows
  ключ шифруется DPAPI для текущего пользователя. При запуске приложение
  повторно проверяет ключ и наличие выбранной модели через `/v1/models`.
- При HTTP 504, временных HTTP-сбоях или сетевом таймауте запрос повторяется и
  переключается только между текстовыми Gemini-моделями маршрутов `agy/` и
  `antigravity/`. Маршрут `gweb` полностью запрещён из-за постоянных HTTP 500.
- Автоматическая цепочка использует Gemini 3.7 tiered, 3.7 low, 3.6 tiered,
  3.5 flash-lite и 3-flash, если они доступны. На каждом маршруте выполняется одна
  попытка; временный отказ сразу переводит пакет к следующему варианту.
- Начало модельных запросов разнесено минимум на 12 секунд. После временного отказа
  агент ждёт 30, затем 60 секунд (или указанный сервером `Retry-After`); после отказа
  всей цепочки действует пятиминутная пауза.
- Локальный 504 `rate-limit execution expiration` означает, что OmniRoute уже сделал
  собственную попытку и оборвал её своим лимитером. Необработанный локальный пакет
  сохраняется и может быть повторён без повторного чтения Zalo.
- Обычные запросы идут в выбранный Gemini-маршрут; OmniRoute распределяет их по
  своему пулу OAuth. Клиентский предел одного вызова — 50 секунд; после него агент
  пробует другой разрешённый маршрут `agy/` или `antigravity/`.
- Сборщик Zalo запускает отдельный сохраняемый профиль Chrome, находит чат по точному
  названию, читает архив экранными пакетами и скачивает доступные изображения без
  OmniRoute. Разметка интерфейса, текст, координаты и связи с медиа сохраняются как есть.
- Для фотографий сохраняются все доступные Zalo URL. Если первый ответ — превью,
  сборщик проверяет остальные варианты и даёт отложенной загрузке изображения до двух
  секунд на переключение на оригинал; для оставшегося превью он открывает именно это
  фото в просмотрщике Zalo, ждёт оригинал до 30 секунд и сохраняет его одним запросом.
  После попытки просмотрщик закрывается; перед чтением сборщик дополнительно возвращается в чат.
- До восьми видимых фотографий скачиваются параллельно. Сохранённые пакеты разбираются
  отдельным потоком одновременно с дальнейшим чтением Zalo; один запрос охватывает до
  восьми перекрывающихся экранов вместо трёх.
- SQLite: сырой архив Zalo и медиа, объекты, предложения источников, сообщения и фотографии,
  версии сообщений, подтверждённые связи, очередь проверки и публикации канала.
- Пакетное сохранение сырого снимка вместе с позицией чтения одной транзакцией.
- Дедупликация по источнику и устойчивому ID; повторная загрузка не дублирует запись.
- Архивный и оперативный курсоры раздельны. Прерванное задание восстанавливается.
- Повторный запуск программы не создаёт второй сборщик с той же базой.
- Резервная копия при открытии; сохраняются последние 7 копий.

Данные macOS: `~/Library/Application Support/BotRieltor/`. Данные Windows:
`%LOCALAPPDATA%\BotRieltor\`. Удаление или пересборка приложения их не удаляет.
Карточки и подтверждения хранятся локально; разрешённые объявления публикуются в
настроенный Telegram-канал.

## Windows

Запустите PowerShell на 64-разрядной Windows 10/11 с Python 3.11+ и Node.js 22+:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1
```

Архив `dist-windows\BotRieltor-Windows-x64.zip` содержит автономный
`BotRieltor.exe` и краткую инструкцию. Сборка добавляет Node.js и интерфейс;
на компьютере запуска должны быть установлены Google Chrome и Microsoft Edge
WebView2 Runtime. Войдите в Zalo из отдельного профиля Chrome, созданного BotRieltor,
и подключите OmniRoute и Telegram в настройках Windows-версии. Windows использует
свою базу, Chrome-профиль и локальные секреты; macOS cookies и ключи не переносятся.

PyInstaller собирает приложение для текущей ОС, поэтому Windows `.exe` нужно
собирать на Windows. Автоматическую сборку также можно запустить из Windows Runner
в `.github/workflows/build-windows.yml` после публикации проекта в GitHub.

## Зафиксированные правила

1. Только Нячанг. Обычно меньше 10 новых объектов в день.
2. Zalo — управление официальным интерфейсом в отдельном профиле Chrome на Mac или Windows.
   Неофициальный API не используется.
3. После перехода в режим GINSENG обрабатываются только новые сообщения, отправленные
   после точки переключения. История, которую сам интерфейс Zalo больше не показывает,
   недоступна для сбора.
4. Старые карточки и отправленные посты сохраняются; переключение источника не удаляет
   архив и не ставит старые объявления в очередь автопубликации.
5. Фото и описание могут быть разными сообщениями. Автор, время, ответы, адрес,
   фотографии и контекст — признаки сопоставления, но время само по себе не доказательство.
6. Надпись «сдано» на фото требует OCR, поиска оригинала и проверки связи с объектом.
   Неоднозначность и конфликт посредников направляются пользователю.
7. **Нет TTL и автоматического снятия по давности.** Статус «Сдан» только по
   подтверждённому сообщению, однозначно связанному с объектом, либо ручной отметке.
8. Площадка публикации — **Telegram-канал**, не группа. Бот — администратор.
   Сданный объект отмечается редактированием существующего поста/подписи.
9. Все вызовы моделей всех агентов идут только через OpenAI-совместимый API OmniRoute.
   Локальный код выполняет инструменты, хранение и API-вызовы Zalo/Telegram без
    прямого подключения к модельным провайдерам.
   Фоновая обработка использует только Gemini через `agy/` и `antigravity/`.
   Claude Opus/Sonnet допускается только отдельным ручным разовым вызовом для сложного
   спорного случая; фоновые задания, fallback и автоматические повторы его не выбирают.
10. Автоматические диалоги с арендодателями Zalo и клиентами Telegram сейчас
    отключены и не реализованы. Будущая переписка — отдельный модуль, отдельные
    разрешения и очередь, а не произвольная отправка через публикации.

## Интеграции и ограничения

UI-адаптер Zalo (`ZaloAgentCollector`) подключён: сборщик ищет чат по сохранённому
названию, подтверждает тип и сохраняет устойчивый идентификатор. Неоднозначное
совпадение уходит на проверку. Затем единственный владелец сессии выполняет
чтение ограниченными пакетами, изображения, устойчивые ID, повторный
просмотр области последнего курсора для пропущенных/изменённых сообщений.
При потере входа/недоступной истории — явное состояние ошибки, не фиктивное завершение.
После ночного перерыва читать пропущенное; новое сообщение не считается новым объектом.

OmniRoute используется как единственный шлюз моделей. Разборщик читает сохранённый
локальный архив и связывает текст с фотографиями. Содержимое переписок — недоверенные
данные, не инструкции агенту. Секреты не хранятся в исходниках, сообщениях или журнале.

Telegram publisher собирает пост по фиксированному формату, отправляет фотографии
альбомом и сохраняет ID сообщений канала. Перед отправкой объявление проходит проверку;
при неясных данных оно остаётся на проверке. Автоматические диалоги с арендодателями
Zalo и клиентами Telegram отключены и не реализованы.
